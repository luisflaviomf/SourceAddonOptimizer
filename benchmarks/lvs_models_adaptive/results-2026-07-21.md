## Verdict

Maximum Adaptive v2 is promoted over the experimental Maximum at `8812c7a`.
Across the eight frozen real families it reduced comparable Models bytes by
27.746%, versus 15.779% for current Models Normal. It saved 24,905,054 bytes,
10,742,110 more than Normal, while all 48 model units compiled and passed the
MDL/VVD/DX90/material/skin-family integrity contract. DX80 is excluded from
both sides of every percentage and is absent from all final outputs.

This is not a universal 50% result. Per-family reductions range from 15.144%
to 42.280%. The fidelity-first fallback intentionally retains more geometry in
the Pontiac wheel, where Normal showed a strong normal error. Runtime remains
the main limitation: v2 took 7.39x the wall time and 9.70x the CPU time of
Normal on this corpus.

## Why the old Maximum was rejected

The exact `8812c7a` Touareg run was stopped after more than 22 minutes without
producing a family output. It generated 1,184 PNGs, 125 JSON files, and 5,379
work files while still processing the first of two model families. Its
roundtrip control grew to 8,418,069 bytes (-1.036%); two full candidates at
5,760,533 bytes (30.860%) and 6,134,489 bytes (26.372%) were rejected, and the
third candidate had only started. Because no family was promoted, assigning it
a fake 0% or 100% preservation result would be misleading.

## Implemented architecture

1. The existing Models Normal output is the seed, at the frozen aggressive
   ratio of 0.35.
2. QC render occurrences are split into deterministic material-connected
   regions. Curvature, silhouette exposure, hard edges, UV seams, transparency,
   semantic names, and bone-weight gradients determine risk and budget.
3. meshoptimizer simplifies indexed regions with position/normal/UV/weight
   attributes and locked borders. Ambiguous correspondence fails locally.
4. A passing Normal region may try one more aggressive candidate. A failing
   region may try one lighter recovery. There is no dozens-of-full-candidates
   search.
5. Failed regions alone return to the Normal or original representation. A
   wheel or glass failure does not preserve the car.
6. CPU geometry metrics run first; Blender is only a targeted near-limit or
   semantic escalation. StudioMDL runs once for final family composition, with
   local compile isolation only on failure.
7. The optional framework path is read-only resolution input. Reference
   closure validation forbids new dependencies in the produced addon.

## Rejected exact silhouette EDT performance experiment

The Pontiac holdout was rerun cold while replacing the exact Python KD-tree
boundary queries with three exact squared Euclidean distance-transform (EDT)
variants. All variants preserved the same 19 regional decisions, 13,530 final
triangles, 833,184 comparable bytes, one targeted render, one StudioMDL
compile, zero integrity failures, and zero final DX80 bytes. The compiled MDL,
VVD, DX90 VTX, and PHY hashes were byte-identical to the baseline.

| Exact boundary implementation | Adaptive wall | Adaptive CPU | Render wall | Total wall | Verdict |
|---|---:|---:|---:|---:|---|
| Existing Python KD-tree | 27.117 s | 23.609 s | 5.073 s | 56.012 s | Retained |
| Python full-grid EDT | 39.733 s | 37.906 s | 5.620 s | 69.603 s | Rejected |
| Native full-grid EDT | 27.620 s | 25.516 s | 9.825 s | 66.729 s | Rejected |
| Native compact boundary EDT | 27.116 s | 25.094 s | 11.974 s | 74.586 s | Rejected |

The native transform itself took 1.624 ms per 256px field, but converting its
65,536 integers to Python took another 7.837 ms. Returning only compact boundary
distances removed that transfer cost and improved the unit suite, but did not
reduce the real adaptive stage. Render-wall variation was external to the EDT
and is shown separately. Since no variant met the <=20.338 s promotion gate,
all production EDT code and its ABI change were reverted. Evidence is retained
under `C:\gaco-max-v2-perf-exact`, `C:\gaco-max-v2-perf-native-exact`, and
`C:\gaco-max-v2-perf-native-compact`.

## Rigorous adaptive performance investigation

A subsequent investigation changed no production algorithm and isolated only
the Pontiac `adaptive-simplification` stage. Five unprofiled cold runs measured
29.342 s median (27.627–31.776 s); five warm region-cache runs measured 24.931 s
median (23.644–29.988 s). All decisions, samples, arrays, metrics, gates,
composed sources, and frozen compiled hashes remained exact.

A low-overhead outer decomposition accounts for 99.859% of stage wall without
double counting. Original reference preparation plus candidate measurement is
80.424%. Detailed child timings attribute 58.570% to silhouettes and 17.594%
to 9,216 3D nearest queries; native meshoptimizer itself is only 0.149%.

The complete methodology, ten measurements, cProfile self/cumulative table,
BVH/query distribution, cross-type checks, Amdahl ceilings, and exact next
experiment design are in
`docs/superpowers/specs/2026-07-21-models-maximum-v2-performance-investigation.md`.
Raw evidence is retained under `D:\gaco-max-v2-rigorous-profile-20260721`.
No optimization or release was produced by this investigation.

## Exact fused raw-mask silhouette experiment

The approved next experiment replaced only the opt-in silhouette measurement
path with one native batch call over the raw masks. Unlike the rejected EDT,
it also moves four-neighbour boundary extraction, bidirectional distance work,
p95 selection, and IoU counting into that call, reuses buffers, and returns
only the required metrics. The approved KD path remains the default.

All 10,000 mask-oracle cases, three frozen cross-type regions, every timed
pipeline semantic fingerprint, and the final MDL/VVD/DX90/PHY tree were exact.
The warm Pontiac silhouette median improved from 4.945754 s to 1.430013 s
(3.459x); the adaptive median improved from 8.831737 s to 5.329917 s
(-39.65%). The paired real full-family run improved from 23.490257 s to
19.398184 s (-17.42%) with identical 833,184-byte compiled output. Warm peak
RSS rose 0.788% in the isolated runner and fell 0.221% in the real full run.

The result meets every promotion gate, so the source is retained as an opt-in,
unshipped experiment pending integration approval. `_nearest` now consumes
37.81% of the adaptive diagnostic (1.999822 s / 9,216 calls) and is the next
justified target, but it was not changed. Full methodology, every individual
timing, decomposition, Amdahl calculation, limitations, hashes, and artifact
paths are in
`docs/superpowers/specs/2026-07-21-models-maximum-raw-mask-silhouette-result.md`.

## Remaining limitations

- Runtime is still substantially above Models Normal and is the next clear
  optimization target; the dominant work is regional metric sampling, not full
  Blender candidate rendering.
- Very fragmented/nonmanifold or unconfident component correspondence restores
  only the unmapped source region. That is safe but can leave compression on
  the table.
- The eight-family vehicle corpus strongly exercises wheels, glass, bodywork,
  lights, UVs, and rigging, but it is not proof for every Source addon class.
- Aggregate observed skinning metrics should be added to a future report schema;
  this release guarantees the strict per-region bound and compiled contracts.
